## [0.5.0] - 2026-05-08

### Added
- Auth Service with registration, login, and JWT authentication
- API Gateway with Spring Cloud Gateway MVC
- Eureka Service Discovery
- Spring Cloud Config Server
- Model Registry Service with MongoDB
- RabbitMQ message broker
- Redis cache
- PostgreSQL databases for core services
- MongoDB for Model Registry
- MinIO object storage
- ELK Stack for centralized logging
- MailHog for local email testing
- GitHub Actions CI/CD pipeline
- AI Services directory structure (university-ranking-predictor, personality-classifier, fake-news-detector, vehicle-price-predictor, job-recommender)
